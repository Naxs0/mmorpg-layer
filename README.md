# MMORPG Layer

Mod de Fabric para **Minecraft 26.3** que convierte el juego en un MMORPG: niveles, oficios, armas con habilidades,
mazmorras, poblados, monturas y una historia propia, "La Cadena de Aurelia".

## Descargas

Las versiones están en **[Releases](../../releases)**.

## Instalar (solo la primera vez)

1. Instala **Fabric Loader** para Minecraft 26.3.
2. Descarga de la última versión estos archivos y ponlos en la carpeta `mods`:
   `mmorpg-mod-<versión>.jar` y `fabric-api-<versión>.jar` (y, para las animaciones, los dos de EMF/ETF).
3. Abre el juego.

## Actualizar

No hace falta hacer nada: al abrir Minecraft, si hay una versión nueva aparece arriba del menú principal el botón
**"Actualizar MMORPG Layer"**. Un clic, cierras el juego y al volver a abrirlo ya está instalada.
